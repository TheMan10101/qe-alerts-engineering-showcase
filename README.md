# QE Alerts
### Python Event Detection | Time-Series Monitoring | Automated Notifications

**Independent Software Engineering Project**

QE Alerts is an independently developed Python-based event detection and notification system designed to monitor time-series information, identify qualifying events, and communicate structured alerts.

The project focuses on reliable event processing, data validation, notification quality, automated testing, and human-controlled configuration.

## Engineering Highlights

### Event-Driven Processing
- Directed and reviewed AI-assisted development of Python-based event monitoring workflows.
- Developed configurable processing for time-series conditions and event classification.
- Incorporated event deduplication and cooldown controls to reduce repeated notifications.
- Organized alert processing around structured events and persistent state.

### Data Engineering & Reliability
- Used SQLite for structured event persistence.
- Applied input validation, event-state tracking, and data-quality checks.
- Used automated testing to validate core event-handling behavior.
- Emphasized reproducibility, error handling, and observable system behavior.

### Notifications & User Interface
- Developed a mobile-accessible alert feed.
- Integrated audible notification behavior.
- Supported differentiated notifications based on event significance.
- Designed around actionable information and minimizing unnecessary alerts.

## Technical Stack

- **Language:** Python
- **Database:** SQLite

- **Testing:** Automated Python tests
